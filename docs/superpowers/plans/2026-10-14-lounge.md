# Lounge Implementation Plan

> **For agentic workers:** executed natively in-session (user requested autonomous execution to completion). Steps use checkbox syntax for tracking.

**Goal:** Build Lounge, a controller-only big-picture media center for Windows, as specified.

**Architecture:** One WinExe (`Lounge.exe`, Avalonia 11.3) plus a WinForms helper (`LoungeAgent.exe`). Pure logic lives in `Core/` (no Avalonia, unit-tested). The FFmpeg playback engine lives in `Media/` (no Avalonia, tested against generated sample clips). The UI lives in `Shell/`, `Screens/`, `Themes/` and `Controls/`. Win32 interop (XInput, Core Audio, foreground) lives in `Platform/`.

**Tech stack:** .NET 10, Avalonia 11.3.22, FFmpeg.AutoGen 8.0.0.1 (FFmpeg 8.0 DLLs from MSYS2 mingw64, the same set tivi bundles), libass-9 via P/Invoke, NAudio 2.2.1 (WASAPI output and endpoint volume), Microsoft.Web.WebView2 (Core API hosted in a NativeControlHost), Microsoft.Data.Sqlite, xUnit, Avalonia.Headless.

**Spec:** `docs/superpowers/specs/2026-10-14-lounge-design.md`

## Global Constraints

- Data root `%APPDATA%\fezcode\Lounge\`; never touch `%APPDATA%\fezcode\tivi\`.
- `config.ini` / `history.ini` use tivi formats; history line `position|duration|sub_delay_ms|last_seen_unix|path`, cap 400.
- No module reads gamepad state except `Platform/XInputPad` → `Core/Input/ActionRouter`.
- Every user-facing behaviour is a `SettingDescriptor`; the settings UI is generated from them.
- Minimum text 22px at the 1920×1080 design grid.
- `-h/--help`, `-v/--version`, `--selftest` on Lounge.exe; `-h`/`-v` on LoungeAgent.exe.
- Commits: normal title and body, no Co-Authored-By or AI attribution; use `git commit -F`.
- `Core/` and `Media/` must not reference Avalonia (enforced by a test).

## Review Focus

1. Controller unplugged mid-scrub or mid-rename → overlay appears, state is preserved, nothing is left half-renamed (test: router context reset on disconnect).
2. Rename to an existing name or with invalid characters → rejected with a message, not an exception (FileOps tests).
3. `history.ini` with malformed lines or paths containing `|` → bad lines skipped, the path keeps everything after the 4th `|` (WatchHistory tests).
4. Hold/chord bindings overlapping (View tap vs. hold View vs. View+Menu) → the tap fires only on release under the hold threshold, and a chord suppresses both (Keymap tests).
5. settings.json from a future or corrupt version → backed up, defaults loaded, no crash (Settings tests).

## Tasks

### Task 1: Scaffold
Create `Lounge.csproj`, `tests/Lounge.Tests.csproj`, `Agent/LoungeAgent.csproj`, `tools/Preview`, `.gitignore`, `.gitattributes`, `NuGet.Config`, `app.manifest`, `Core/Product.cs`, `Program.cs` (help/version/selftest), `LICENSE.txt`, `properties.piml` (`(airlift) true`), `AGENTS.md` (release flow adapted from SirWordALot), `version.ps1`, `build.ps1`, `installer.ps1`, `forge.toml`, `tools/fetch-native.ps1` (copies the FFmpeg + libass DLL closure from MSYS2 into `native/win-x64`).

### Task 2: Core — settings
`Core/Settings/SettingDescriptor.cs`, `SettingsSchema.cs` (all descriptors), `SettingsStore.cs` (JSON, atomic, migrations, corrupt backup), `IniFile.cs` (tivi key=value), `PlayerConfig.cs`. Tests: defaults, round-trip, corrupt file, future schema, every descriptor has a section and label.

### Task 3: Core — input
`Core/Input/PadState.cs`, `PadButton.cs`, `InputBinding.cs` (button / hold / chord / trigger band), `Keymap.cs` (+ JSON, defaults), `ActionRouter.cs` (contexts, hold/tap disambiguation, repeat on held D-pad, trigger bands, return chord), `Actions.cs`. Tests: tap vs. hold, chord suppression, context fall-through, repeat timing, trigger bands, remap conflicts.

### Task 4: Core — media data
`Core/Media/WatchHistory.cs`, `NaturalSort.cs`, `PlayQueue.cs`, `MediaKinds.cs` (extension tables), `SidecarSubs.cs`. Tests per Review Focus 3.

### Task 5: Core — files and library
`Core/Files/FileOps.cs` (rename validation, copy/move with progress, Recycle Bin via SHFileOperation, new folder), `Core/Library/LibraryDb.cs`, `LibraryScanner.cs`, `Tiles.cs` (tiles.json). Tests: rename collisions, invalid chars, extension lock, scanner incremental.

### Task 6: Core — launcher/dormant, ambient synth, themes
`Core/Launch/DormantState.cs`, `Core/Audio/AmbientSynth.cs` (procedural, original pads per theme), `UiSounds.cs`, `Core/Themes/ThemeDefinition.cs` + 5 definitions. Tests: dormant transitions, synth deterministic and non-silent, theme tokens complete.

### Task 7: Media engine
`Media/Ffmpeg.cs` (loader), `Demuxer`, `VideoDecoder` (D3D11VA → transfer → NV12/yuv420p frames), `AudioDecoder` (swr + atempo graph), `AudioOutput` (NAudio WASAPI, clock), `SubtitleRenderer` (libass P/Invoke + bitmap subs), `Player.cs` (state machine, seek, exact seek, scrub stepping, speed, tracks), `Thumbnailer.cs`, `MediaProbe.cs` (tags, duration, cover art). Tests against clips generated by ffmpeg.exe at test time (skipped if FFmpeg is unavailable): open, duration, exact seek within one frame, thumbnail, tags, subtitle sidecar render.

### Task 8: Platform
`Platform/XInputPad.cs` (+ vibration), `SystemVolume.cs`, `Foreground.cs` (bring-to-front, foreground pid), `SingleInstance.cs` (mutex + pipe), `StartupRegistration.cs` (Run key for the agent), `CursorMode.cs` (SendInput mouse).

### Task 9: Shell framework
`Shell/MainWindow.cs` (fullscreen, 1920×1080 Viewbox, layer stack: backdrop / screen / overlay / toast / dialog), `Navigator.cs`, `FocusEngine.cs` (spatial), `Spring.cs` animator, `Controls/Tile.cs`, `GlassPanel.cs`, `Icons.cs`, `Toasts.cs`, `Dialogs.cs`, `OnScreenKeyboard.cs`, `VolumeHud.cs`, `ControllerOverlay.cs`.

### Task 10: Screens
`Screens/Home/*` (5 layout variants), `VideosScreen`, `MusicScreen`, `NowPlayingScreen`, `FilesScreen`, `SettingsPanel` (generated), `RemoteScreen` (controller drawing + capture), `PlayerScreen` (video surface GL + CPU fallback, OSD, tracks panel, next-up, scrub strip), `WebScreen` (WebView2 host), `AppsScreen` + `TileEditor`.

### Task 11: Agent
`Agent/Program.cs` (WinForms toast, XInput connect polling, quiet rules, reads settings.json `agent.*`).

### Task 12: Verification and release prep
`tools/Preview` renders every theme's home, the settings panel, the OSK, the remote screen and the files screen to PNG headlessly. `build.ps1` runs tests + preview + selftest and publishes Lounge + Agent + native DLLs into `dist/Lounge`. Write the README with a banner. Run the installer build.
